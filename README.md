# Boolflix — Movie & TV Search

A Vue 3 and Vite learning project that searches movies and TV series through the [TMDB API](https://www.themoviedb.org/).

![Vue](https://img.shields.io/badge/Vue_3-42b883?logo=vuedotjs&logoColor=white) ![Vite](https://img.shields.io/badge/Vite-646CFF?logo=vite&logoColor=white)

## Features
- Search for movies and TV series.
- Retrieve matching results with Axios.
- Display results in Vue components.

## Tech stack
Vue 3 · Vite · JavaScript · Axios · Bootstrap · Sass · Font Awesome.

## Run locally
```bash
npm install
npm run dev
```
Run `npm run build` to prepare a production build.

## Security / deployment note
The current source code contains a TMDB API key directly in a client-side file. Review and rotate this key if needed and check the provider's terms before deploying publicly.

## Project context
An educational frontend project. Not affiliated with Netflix or TMDB.
